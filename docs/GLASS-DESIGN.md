# 萌知 — 液态玻璃界面修订

用户要求：名称带「萌」，有实际含义；页面采用苹果液态玻璃风格。最终暂名「萌知」，取「萌生新知」，截图中的信息经过识别成为可编辑资料。

本修订覆盖 DESIGN.md 原浅灰平面风格。finesse：register=product，design-language=apple，apple-mode=app + spatial materials。

## 可观察的设计

- 清透的浅色窗口，原生圆角及阴影；侧栏与工具栏使用玻璃材料，编辑正文保持高不透明度。
- 标注工具改为悬浮胶囊，细亮边、轻内高光，选中工具的底板在胶囊内部移动；不反复缩放整个窗口。
- 主画布安静、图片完整；右侧识别区是一块独立圆角阅读面，使用 18–22px 内边距。
- 控件统一 32–36px，主要动作与选中态采用石墨黑/深灰；工具与导出按钮更圆润，但正文卡片不全部做成胶囊。
- 不打包苹果字体或 SF Symbols，使用平台系统字体和原创矢量图标。
- macOS 优先接入系统原生材料；Windows 使用相应系统材料或清晰的不透明替代。跨平台视觉近似不宣传为每台电脑都有 Apple 原生 Liquid Glass。

## 动态与可访问性

- 120ms 工具/选区反馈，160ms 面板出现；拖动和画笔保持实时跟手。
- 动效可中断；避免动态模糊、大面积循环光效与色散。
- 「减少动态效果」和「减少透明效果」独立设置；跟随可读取的系统偏好。减少透明效果时提高表面不透明度并保留边界。
- 工具/导航可透，文字校对和表格不可依赖背景颜色才读得清。测试浅色、深色与不透明替代。

参考：[Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)，finesse-ui/references/apple-design.md、interaction-motion.md。

## 选中态（用户追加要求）

所有互斥工具/标签按钮：浅色界面下当前项使用石墨黑 #303237，深色界面下使用深灰 #555b65，文字和图标纯白；切换后上一项恢复默认表面。主要动作同步采用这套中性色；悬停和按下使用各自的灰阶。选中态跟随业务状态持续存在，不使用仅按下时有效的 :active。原生图标为绘制后的位图，必须在 toggled 时重新着色，不能只改文字 color。控件仍有键盘焦点与禁用状态。截图选区、取色标记保留独立的功能色。一次性的保存/复制动作不伪装成持续选中的工具。
