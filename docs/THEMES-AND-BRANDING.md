# 萌知主题与图标

提供石墨玻璃、暗夜石墨、深空蓝、夜蓝、星云紫、冰川银六套主题。顶部「主题」或偏好设置中切换，即时应用并保存。所有主题使用独立的背景、阅读面板、文字、边框与工具栏配色；选中工具采用实心石墨灰、白色图标和主题色细边。工具栏底色不透明，配合边框和轻阴影提高识别度。

动效：主题切换 160 ms 淡入；工具选中框 180 ms 移动。开启减少动态效果后直接显示最终状态。截图原图、标注颜色与导出内容不随主题改变。

快捷键：偏好设置可录入截图与贴图组合，提供恢复默认和显式保存。录入时暂停全局注册；空组合、多段组合、重复、保留组合和系统占用时显示修正提示，失败不覆盖旧设置。关闭偏好设置后启用已保存的组合。支持 F1–F20，或带修饰键的字母、数字、空格组合。

原创图标以「取景框内萌生新芽」表达截图与萌生新知。深蓝绿图标底板、白色取景框、薄荷绿嫩芽，确保小尺寸仍有明确轮廓。可编辑源文件为 assets/branding/mengzhi.svg；脚本 scripts/build_branding.swift 无外部依赖，生成 PNG、macOS ICNS 与多尺寸 Windows ICO。图标已接入工作台、窗口、托盘、macOS 包资源以及 Windows 资源配置。Windows 安装包和真实系统图标显示仍需 Windows 构建验证。

夜蓝参考 Telegram 夜间界面的深蓝灰层次，使用较深画布、稍亮阅读面板和蓝色交互提示；旧极光青偏好自动映射至夜蓝。按钮使用分层玻璃渐变、半透明高光边缘、150 ms 悬停提亮与按下反馈；工具选中仍保持实心石墨底与白图标。
