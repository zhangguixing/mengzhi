## 全局使用习惯

- 日常路径：F1 → 选区 → 标注 → Enter/Ctrl+C；F3 → 贴图。工作台只负责 OCR 校对和导出。
- 截图 Enter、双击、Ctrl+C：复制并退出；Ctrl+S：保存；Ctrl+Shift+S：快速保存；Ctrl+T 或中键：贴图。
- Esc 随时取消/隐藏；右键在非编辑时取消，在编辑时结束当前图形。
- 贴图滚轮缩放，Ctrl+滚轮改变透明度，中键复位；数字键旋转和镜像；空格标注。
- 快捷键可自定义，注册冲突必须提示；macOS 功能键受系统设置影响，提供等价组合键并保留熟悉映射。
- 托盘左键截图、中键贴图、右键菜单；按平台可用的鼠标事件实现并验收。
- 通用偏好：主题色、字体、保存位置、历史上限、快捷键、托盘提示；基础命令行调用。
