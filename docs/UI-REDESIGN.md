# 萌知原生界面改版 · 2026-10-30

采用 finesse-ui 的产品工作台方向，最终选择石墨光台：原图优先，右侧识别校对，底部横向历史。实现使用 Qt Widgets / QPainter / QVariantAnimation，不引入浏览器运行时。

用户要求先生成设计图再实现。参考图通过内置 image_gen 生成并保存为 `assets/design/mengzhi-ui-approved-reference.png`。该文件名表示本轮施工参考，未表示用户逐像素签署验收。生成方向是深石墨工作台、冰蓝主要操作、明亮文档、独立识别面板、紧凑标注与缩放操作、底部历史胶片。实际界面经过 1360×860 和 1024×720 原生渲染检查。

用户随后提供 Snipaste 浮动工具栏截图，明确要求图标一致，因此截图与贴图浮动栏以这张后续参考为准，覆盖生成图中的浮动栏样式。工作台保留原定深色设计。

## 浮动工具栏

- 第一行按参考排序：形状组、折线、箭头、钢笔、马赛克、文字、橡皮擦、撤销、重做、取消、贴图、保存、复制。
- 第二行：线宽、填充、矩形、椭圆、当前颜色、两行十列色板。
- 方形蓝色选中态、浅灰直角面板；图标用独立 20 单位网格描绘，避免套用工作台圆角图标。
- 按钮保留中文说明、快捷键、悬停/按下/禁用/选中状态。颜色弹窗支持透明度；填充形状写入标注历史。
- 更多菜单保留马克笔、模糊、OCR、工作台、快速保存。截图与原位贴图编辑共用 CaptureToolbar。

## 位置与阴影

直接贴图传递全局逻辑选区，图片内容首帧即位于原截取位置。外层增加 20px 透明余量承载方向性多层柔影；阴影不进入复制或保存的源图。

截图复制时，在标准图片载荷旁附带私有位置元数据。F3 能从本应用复制的截图恢复位置；其他应用得到标准图片。普通外部图片沿光标附近贴出。图片拖动、中键复位、缩放与标注均以内容区域计算，避免阴影边距造成偏移。

## 动效与操作

- 工具选中底板 140ms，连续切换可中断。
- Ctrl+滚轮以鼠标下源像素为锚点缩放，140ms 缓出，快速滚动累加目标；25%–800%。
- 中键拖画布 1:1，不切换绘图工具；适应窗口恢复缩放和平移。
- 专注模式收起结果与历史，Tab 切换，Esc 恢复；Ctrl+Enter 识别。
- 原位贴图不播放飞入或居中动画。应用或系统减少动态效果设置下，缩放及反馈立即到达最终状态。

## 验证与边界

最终 Release 的 export_tests、ocr_tests、capture_tests、canvas_interaction_tests 四组自动测试通过。原生窗口边界检测、工具栏绘制、双击复制动作与标注保持完成 Windows 后端验证。

当前命令执行宿主调用 Windows OpenClipboard 返回错误 5（拒绝访问），原生后端的两项剪贴板读回断言因此失败；offscreen 后端的图像与位置元数据回归通过。桌面交互工具能发现应用及控件，但激活窗口失败，截图返回桌面画面。因此不能宣称完成系统剪贴板或全局快捷键的完整实机验收。
